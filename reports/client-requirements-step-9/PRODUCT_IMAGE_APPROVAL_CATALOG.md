## 5. Identified Photography Gaps for Full Production Launch

While the 12 photoshoot assets successfully establish a high-couture aesthetic across the homepage, catalogue, and PDP hero spots, the following supplementary angles should be captured during the next atelier shoot for production perfection:
1. **Back View (360° Silhouette)**: Patrons purchasing wedding sherwanis benefit from seeing rear architectural seam lines and vent tailoring.
2. **Fabric & Embroidery Macro (50mm Close-Up)**: Extreme close-up of zardozi metallic wirework, resham thread density, and button finish.
3. **Inner Lining & Pocket Craftsmanship**: Visual verification of silk/viscose inner lining and interior ticket pockets.
4. **Model Specifications**: Recording model height (e.g., 6'1") and worn size (e.g., Size 40) for patron fit contextualization.

## 6. Structured Content Intake Template for Client Ankur

Following visual approval of the photographs above, client Ankur or the merchandising director should supply the specific garment attributes using the template below for each product:

```markdown
### Product Information Submission Form

1. Product ID / Reference: [ e.g. waak-01 / The Ivory Zardozi Sherwani ]
2. Official Marketing Title: [ Exact commercial name to be displayed ]
3. Short Subtitle / Descriptor: [ e.g. Handcrafted Banarasi Silk with Antique Gold Wirework ]
4. Pricing Details:
   - Retail Selling Price (₹): [ e.g. 49,500 ]
   - Comparative Original MRP (₹): [ e.g. 56,000 ]
5. Fabric & Composition:
   - Primary Outer Shell: [ e.g. Pure Banarasi Katan Silk / Italian Wool / Micro-Velvet ]
   - Inner Lining: [ e.g. Breathable Cotton-Silk / Cupro Viscose ]
   - Weight & Seasonality: [ e.g. Heavy Winter Wedding / Year-Round Lightweight Festive ]
6. Craftsmanship & Ornamentation:
   - Embroidery Technique: [ e.g. Hand-pulled Zardozi wirework / French knots / Machine Resham ]
   - Metalware & Buttons: [ e.g. Antique brass / Silver plated / Fabric wrapped ]
7. Fit & Silhouette:
   - Cut: [ e.g. Structured Architectural / Relaxed Comfort / Slim Tapered ]
   - Model Reference: [ e.g. Model is 6'1" wearing chest size 40 ]
8. Supported Sizes: [ 36, 38, 40, 42, 44 ]
9. Garment Care: [ e.g. Strictly dry clean only; protect from moisture and perfume ]
10. Expected Dispatch Timeline: [ e.g. Ready to ship in 3-5 business days ]
```
